Source to HTML Converter
Overview
Source to HTML Converter is a C-based application that converts C source code files into HTML files with syntax highlighting. The generated HTML file can be opened in any web browser to view the source code with improved readability through color-coded syntax elements.

The project demonstrates parser design using a State Machine (State-Event) approach and provides a practical understanding of lexical analysis concepts.

Features
Converts C source files into HTML format


Syntax highlighting for:
Keywords
Preprocessor directives
Comments
Strings
Character constants
Numeric constants
Optional line number display
Custom output file name support
Browser-friendly HTML output


Technologies Used
C Programming Language
File Handling
String Manipulation
State Machine Design
Command Line Arguments
HTML Generation
